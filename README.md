The primary packet is written for a hiring reviewer. The repositories add direct
traceability from business requirements and workflow decisions to data models,
implementation, tests, deployment controls, and evaluation.

Public examples retain only the non-confidential evidence needed to understand
the work. They do not contain employer source code, active customer records,
credentials, access logs, or proprietary ranking criteria.
